# Student outcomes dataset

WolfHacks 2026: Data Science & AI Track: Synthetic Student Outcomes Dataset

800 synthetic student-course records representing data an AI study dashboard could collect by the end of a semester.

All data is computer-generated. No real students are represented. Values follow built-in patterns plus random noise.

at_risk = 1 if the student finished the course with a D or F (final score below 70), otherwise 0. About 28% of records are 1."

- `student_outcomes.csv` — one row per student per course (800 rows)
